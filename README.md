# 감정 및 욕구 찾기

© 2026 Jaecheol, LIM. All rights reserved. 무단 복제·배포를 금지해요. → [LICENSE](LICENSE)

오늘 있었던 일에서 **내 감정의 이름**과 **그 밑의 욕구**를 찾아보는 휴대폰 웹앱이에요.
진단이나 검사가 아니라, 감정 낱말을 익히고 내 마음을 살펴보는 도구예요. 서버·AI·로그인이 없어요.

설계 규칙(다시 깨지면 안 되는 것): [docs/design-rules.md](docs/design-rules.md)

## 처음 화면 (표지)

- 제목 **감정 및 욕구 찾기**, 그 아래 **시작하기** 버튼(편안한 파랑) 하나만 크게 있어요.
- 왼쪽 위 **글자 크게**를 누르면 모든 화면의 글자와 버튼이 커져요(어르신·어린이용). 다시 누르면 보통 크기예요.
- 아래쪽에 **감정 도감 · 주간 보고서 · 지난 기록 · 기록 옮기기** 4개가 한 줄로 있어요.
- 오른쪽 위 **사용 방법**(남색)을 누르면 순서 안내, 홈 화면에 설치하는 방법, 설계에 참고한 자료(논문·책, 제목을 누르면 펼쳐짐)가 나와요. 처음 열 때 한 번 자동으로 나와요.
- 처음 화면의 글자는 가운데 맞춤이에요. 기록이 생기면 아래쪽 메뉴 바로 위에 "기록 ○개 · 도감 ○ / 651 · 연속 ○일" 한 줄이 나와요.

## 순서

1. **있었던 일** — 1~3줄 (적지 않고 시작해도 돼요)
2. **감정 고르기** — 번호 붙은 세 묶음에서 골라요. 위에서 아래로 서로 돕는 차례예요. **개수 제한이 없어요.** 다시 누르면 풀려요.
   - **1 기분 4칸으로 찾기**(무드 미터, 얼굴 그림, 맨 위): 노랑(기분이 좋고 힘이 넘침) · 초록(기분이 좋고 차분함) · 빨강(기분이 안 좋고 힘이 셈) · 파랑(기분이 안 좋고 힘이 빠짐). 칸을 누르면 범주별 감정 낱말이 펼쳐져요. 다른 칸을 열어도 고른 감정은 남아요.
   - **2 핵심 감정으로 찾기**: 6개(수치심 · 죄책감 · 분노 · 두려움 · 상실감 · 슬픔)가 얼굴 그림과 함께 3개씩 두 줄로 있어요.
   - **3 다른 방법으로 찾기**(1·2에서 찾기 어려울 때): 아래 3가지가 같은 모양의 줄 단추로 모여 있어요.
   - **상대가 나에게 한 일로 찾기**(따로 한 화면): "무시당했다"처럼 상대가 한 일에 대한 생각이 섞인 말 35개를 여섯 묶음으로 보여 줘요. 낱말로 찾기에 "무시당했다"라고 적어도 이어져요. 누르면 그 밑에 있을 수 있는 느낌(골라 체크)과 욕구 후보를 보여 줘요.
   - **🔍 낱말로 찾기**: "부끄러웠다", "서운해요"처럼 적어도 찾아요.
   - **잘 모르겠어요**: 몸 느낌 → 하고 싶었던 행동 → 욕구부터 거꾸로 → 비슷한 옛 경험 → 그래도 없으면 "이름 붙이기 어려운 감정"
   - 감정을 고르면 위쪽 막대에 모여요(안 골랐을 때는 막대가 없어요). ✕로 뺄 수 있어요.
3. **강도** — 고른 감정이 한 화면에 모두 나오고, 감정마다 1~10을 골라요. 잘못 고른 감정은 **빼기**, 잘 모르겠는 감정은 **보류**(강도 없이 카드에 따로 적힘). 둘 다 **되살리기**로 되돌려요. 감정 낱말은 크고 진하게, 칸 색으로 강조돼요.
4. **원인** — 그 사람의 말 / 태도 / 결과 / 내 기대 / 다른 것
5. **욕구 고르기** — 감정과 같은 차례(1 먼저 살펴볼 욕구 → 2 14범주 → 3 다른 방법)로 골라요. **개수 제한이 없어요.**
   - **먼저 살펴볼 욕구**: 고른 감정과 함께 흔히 보이는 욕구(경향일 뿐 정답 아님). 마음 카드에서 "네"라고 답한 욕구는 앞에, "아니요"가 더 많았던 욕구는 빠져요.
   - **욕구 14범주**: 몸·쉼 / 안전·안정 / 연결·사랑·소속 / 존중·인정 / 이해·공감 / 정직·진정성 / 자율·자유 / 놀이·재미 / 평화·조화·아름다움 / 의미·기여 / 성장·성취 / 자기표현·창조 / 나다움·자기 돌봄 / 한계·자기조절
   - **🔍 욕구 낱말로 찾기**, **지금은 넘어가기**
6. **마음 카드** — 감정·강도·보류한 감정·욕구·한 줄 정리. "고른 욕구가 맞았나요?" 네 / 아니요 / 잘 모르겠음

**이동 단추**: 처음 화면을 뺀 모든 화면 맨 아래에 같은 모양의 "← 이전"(흰 단추)·"다음 →"(파란 단추)가 있어요.

**이전 단계로 돌아가기**: 마음 카드를 포함한 모든 단계 화면 왼쪽 위 **← 이전**. 적은 글과 고른 것은 지워지지 않아요. 마음 카드에서 돌아가 고친 뒤 다시 만들면 같은 카드가 고쳐져요(기록이 늘지 않음).

**낱말 수**: 감정 651개(기분 4칸 · 범주 28개, 같은 뜻 다른 말 포함), 욕구 153개(14범주). 근거는 사용 방법 화면 끝의 참고자료와 `docs/` 폴더에 있어요.

**도감·보고서·기록**: 감정 도감(기분 4칸 → 범주 → 감정 낱말 2개씩 나란히, + 단추를 누르면 뜻·비슷한 말·반대말만 펼쳐짐, 골라 본 감정 ✓. 보너스별은 없음), 지난 기록(기록마다 수정·피드백·삭제), 연속 기록 일수, 주간 보고서(서로 다른 감정 수, 여러 감정 기록 수, 하루 평균 강도 그래프, 자주 나온 감정·욕구와 그 짝, 욕구 응답 수, 기분 4칸 나눠 보기)

**기록**은 휴대폰 브라우저 안에만 저장돼요. 처음 화면 맨 아래 "기록 전체 삭제"로 모두 지울 수 있어요.

## 기록 옮기기 (휴대폰을 바꿀 때) 💾

기록은 휴대폰 안에만 있어서, 휴대폰을 바꾸거나 브라우저 데이터를 지우면 사라져요. 그 전에 파일로 저장해 두세요.

1. 옛 휴대폰: 처음 화면 → **기록 옮기기** → **파일로 저장하기**
   (또는 **다른 앱으로 보내기**를 눌러 메일·드라이브·메신저 "나에게 보내기"로 보내요. 이 버튼은 지원하는 휴대폰에서만 보여요.)
2. 그 파일(`maeum-chatgi-backup-날짜.json`)을 새 휴대폰으로 옮겨요.
3. 새 휴대폰: 처음 화면 → **기록 옮기기** → **파일 고르기** → 파일 선택 → **네, 불러올게요**

- 불러오면 지금 있는 기록은 **그대로 두고** 새 기록만 더해요. 이미 있는 기록은 건너뛰어요.
- 도감·연속 기록·주간 보고서는 기록에서 다시 계산되니 함께 옮겨져요.
- ⚠️ 파일 안에는 적은 글이 그대로 들어 있어요. 다른 사람에게 보내지 않도록 조심하세요.

   - 저장소 위쪽 **Settings**(설정) → 왼쪽 **Pages** → **Branch**에서 `main`과 `/ (root)`를 고르고 **Save**
   - 1~2분 뒤 같은 화면 위쪽에 주소가 나와요. 보통 `https://limjc9-sys.github.io/maeum-chatgi/` 이에요.

3. 홈 화면에 앱으로 설치해요. 앱의 **사용 방법 → 📲 홈 화면에 앱으로 설치하는 방법**에 안드로이드·아이폰별 단계가 자세히 있어요(카톡 안의 화면에서는 설치가 안 되니 크롬·사파리로 열기).
   - **안드로이드(크롬)**: 오른쪽 위 ⋮ → "홈 화면에 추가" 또는 "앱 설치"

4. 한 번 연 뒤에는 인터넷이 없어도 열려요.

## 문장 고치는 방법 ✏️

앱에 나오는 **모든 낱말과 문장**은 `data` 폴더 안 파일 3개(`emotions.js`, `needs.js`, `questions.js`)에 들어 있어요. `data/safety.js`는 지금 쓰지 않는 보관용 목록이에요.
코드를 몰라도 **따옴표 안의 글자만** 바꾸면 돼요.

| 파일 | 들어 있는 것 |
|---|---|
| `data/emotions.js` | 기분 4칸(`quadrants`, 얼굴 그림 `face`) → 범주 → 감정 낱말 651개와 설명, 반대말(`antonyms`, 작성자 추정), 핵심 감정 6개(`coreEmotions`)와 얼굴 그림(`coreFaces`), 화면에서 뺀 옛 낱말(`retiredEmotions`, 지난 기록용), 낱말로 찾기 추천(`searchSuggest`) |
| `data/needs.js` | 욕구 낱말 153개와 설명·실천 제안, 욕구 14범주(`needCategories`), 감정 범주별·감정별 욕구 후보(`needsByCategory`, `needsByEmotion`), 생각이 섞인 말 번역표(`thoughtWords`) |
| `data/questions.js` | 질문 문장, 버튼 글자, 안내 문장, 한 줄 정리 문장, 사용 방법과 참고자료(`guide`), 5번 경로(`approaches`) |
| `data/safety.js` | 위험한 말 목록 (지금은 앱에서 쓰지 않음, 목록만 보관) |

### 따라 하기 (GitHub 웹사이트에서)

**1단계.** GitHub에서 이 저장소를 열어요.

**2단계.** `data` 폴더를 누르고, 고치고 싶은 파일(예: `questions.js`)을 눌러요.

**3단계.** 오른쪽 위의 **연필 모양 ✏️ 버튼**을 눌러요.

**4단계.** 바꾸고 싶은 문장을 찾아요.
   찾기가 어려우면 키보드에서 `Ctrl` + `F`(맥은 `⌘` + `F`)를 누르고 그 문장의 일부를 적어 보세요.

**5단계.** **따옴표 `' '` 안의 글자만** 바꿔요.

예를 들어 이 줄이 있으면

```js
  situationTitle: '오늘 어떤 일이 있었나요?',
```

이렇게 바꿔요.

```js
  situationTitle: '오늘은 무슨 일이 있었어요?',
```

**6단계.** 오른쪽 위 초록색 **Commit changes...** 버튼 → 다시 한 번 **Commit changes**를 눌러요.

**7단계.** 1~2분 기다린 뒤 휴대폰에서 앱을 껐다가 다시 열면 바뀐 문장이 보여요.
   (바로 안 바뀌면 한 번 더 껐다가 열어 보세요.)

### 꼭 지켜야 할 약속 4가지 ⚠️

1. **따옴표 `'`를 지우지 마세요.** 문장 앞뒤에 하나씩 꼭 있어야 해요.
2. **문장 안에 작은따옴표 `'`를 쓰지 마세요.** 대신 큰따옴표 `"`를 쓰세요.
   - ❌ `'나는 '괜찮아'라고 말했어요'`
   - ✅ `'나는 "괜찮아"라고 말했어요'`
3. **줄 끝의 쉼표 `,` 와 괄호 `{ } [ ]`는 그대로 두세요.**
4. **`id: '...'` 부분과 영어 이름표는 바꾸지 마세요.** (예: `id: 'joy01'`, `emotions: ['joyH1', ...]`)
   기록과 도감이 이 이름표로 연결돼 있어요. 감정 단어(`word`)와 설명(`desc`)은 마음껏 바꿔도 돼요.

### 문장 속 `{ }` 표시

`data/questions.js`의 한 줄 정리 문장에는 `{감정을}` 같은 표시가 있어요.
앱이 이 부분에 알맞은 말을 넣어 줘요. **중괄호째로 지우지 말고, 그 앞뒤 말만 바꾸세요.**

| 표시 | 바뀌는 말 (예) |
|---|---|
| `{원인}` | 그 사람의 말에서 |
| `{감정을}` | 서운함을 / 짜증을 (을·를을 앱이 알아서 맞춰요) |
| `{강도}` | 많이 |
| `{욕구가}` | 들어 주는 것이 (이·가를 앱이 알아서 맞춰요) |

### 잘못 고쳐서 화면이 이상해졌다면

- 화면에 **"데이터 파일에 문제가 있어요"**가 나오면, 거기 적힌 파일에서 마지막으로 고친 줄의 따옴표·쉼표를 확인하세요.
- 되돌리고 싶으면: 그 파일을 열고 오른쪽 위 **History**(기록)를 눌러, 전에 잘 되던 때의 내용을 보고 똑같이 고쳐 적으면 돼요.

### 감정 낱말을 새로 더하고 싶다면

1. `data/emotions.js`에서 알맞은 칸(노랑·초록·빨강·파랑)의 범주를 찾아 `emotions` 목록에 한 줄을 더해요.
   ```js
   { id: 'blu26', word: '헛헛함', desc: '마음 한구석이 비어 허전해요' },
   ```
2. 새 `id`는 **아직 안 쓴 번호**로 적어요. (노랑 `yel`, 초록 `grn`, 빨강 `red`, 파랑 `blu` 뒤에 번호)
   이미 있는 id는 바꾸거나 지우지 마세요.
3. 뜻이 **같은** 다른 말은 그 낱말의 `same` 목록에 더해요. id는 원래 id 뒤에 a, b, c …를 붙여요.
4. 한 칸이나 한 범주에서만 고르게 하는 장치(개수 제한, "건너뛰기", 여러 감정을 하나로 묶은 칸)를 만들지 마세요. → `docs/design-rules.md`

욕구 낱말은 `data/needs.js`의 `needs`에 한 줄(`id`, `word`, `text`)을 더하고, `needCategories`의 알맞은 범주 `needs` 목록에 그 id를 넣어요. 새 욕구 id는 `nd` + 세 자리 번호예요.

## 파일 구성

```
index.html            첫 화면 틀
css/style.css         화면 모양(색·크기)
js/app.js             화면 동작 코드
data/*.js             낱말·문장 데이터  ← 여기만 고치면 돼요
manifest.webmanifest  홈 화면 설치 정보
sw.js                 인터넷 없이 열리게 해 주는 파일
icons/                앱 아이콘
tests/run-tests.js    자동 점검 (설계 규칙 재발 방지 점검 포함)
tests/fixed-ids.json  지우면 안 되는 예전 id 목록
tools/needfit-report.js  여러 사람의 기록 파일에서 욕구 응답 모으기
docs/                 설계 규칙(design-rules.md), 사람의 창작적 기여 내역(creative-contribution.md), 감정 낱말 조사 자료, 원자료 단어 대응표, 근거 종합 점검(meta-analysis.md)
```

## 욕구 응답 모으기 (개발자용)

여러 사람이 **기록 옮기기 → 파일로 저장하기**로 보내 준 기록 파일을 모아, 감정별로 "고른 욕구가 맞았나요?" 응답을 세요.

```bash
node tools/needfit-report.js 기록1.json 기록2.json > 욕구응답.md
```
