# 내 마음 찾기 💗

오늘 있었던 일 속에서 **내 감정의 이름**을 찾아보는 1인용 휴대폰 게임이에요.
한 판은 5~10분이면 끝나요.

---

## 게임 순서

처음 열면 **게임 방법 안내**(3장)가 한 번 나와요. 다시 보고 싶으면 처음 화면 메뉴의 **게임 방법**을 누르세요.

1. **있었던 일 적기** — 1~3줄 (적지 않고 **적지 않고 시작하기**를 눌러도 돼요)
2. **큰 감정 고르기** — 기쁨 / 슬픔 / 화남 / 불안·두려움 / 부끄러움·미안함 / 놀람 / 싫음·역겨움 / 섞인 마음 / 잘 모르겠어요
   (두 줄로 나와요. 쪽마다 "부끄러웠다, 창피했다, 미안했다…"처럼 예시가 붙어 있어요. "잘 모르겠어요"는 다른 화면의 5번처럼 질문 방법을 바꿔요)
3. **세부 감정 고르기** — 묶음을 고르고, 그 안에서 감정 단어를 골라요
   (묶음은 한 화면에 4개씩 나와요. 더 있으면 5번 **다른 묶음 더 보기**로 다음 장을 봐요.
   슬픔·상실감·화남·분노·두려움·불안함·수치심·죄책감·깜짝 놀람·역겨움 같은 기본 감정은 각 쪽 첫 장에 있어요)
   - **🔍 단어로 찾기**: 쪽·묶음 화면 아래 버튼. "부끄러웠다", "미안했다", "놀랐다"처럼 적으면 맞는 감정 단어를 찾아 줘요 (같은 뜻 다른 말까지)
   - **비슷한 감정 구별하기**: 수치심·죄책감·창피함·민망함처럼 헷갈리기 쉬운 감정을 고르면, "그때 무슨 일이었나" 문장 4개로 견주어 한 번 더 골라요
   - **여러 감정 체크 (3개까지)**: 단어를 누르면 ✓ 표시가 돼요. 다시 누르면 풀려요. 위쪽 "고른 감정" 막대에서 ✕로 빼거나 **다른 쪽에서 더 고르기**로 다른 쪽 감정을 더할 수 있어요. 다 골랐으면 **다음 →**
   - **섞인 마음 쪽**: 착잡함, 시원섭섭함, 웃픔, 고마우면서 미안함, 애증처럼 여러 마음이 섞인 감정
   - 고른 단어에 뜻이 같은 다른 말이 있으면 **평소에 쓰는 말**을 한 번 더 골라요 (예: 실망 · 낙담 · 낙심 · 낙망. 어느 것을 골라도 틀리지 않아요)
4. **강도** — 1~10점 (감정을 여러 개 골랐으면 감정마다 물어요)
5. **원인** — 그 사람의 말 / 태도 / 결과 / 내 기대 / 다른 것
6. **욕구 찾기** — "그 순간 무엇이 있었다면 괜찮았을까요?"
   - 첫 화면에는 고른 감정에 맞는 욕구 4개가 나와요 (예: 수치심 → 받아들여짐·존중·노력 인정·실수해도 괜찮음)
   - 5번 **다른 욕구 찾기** → 욕구 쪽 8개(이어짐·존중·안전·해냄 / 쉼·자유·의미·이해) → 그 쪽 욕구
   - **🔍 욕구 단어로 찾기**: "인정받고 싶었다", "위로받고 싶었어요"처럼 적어도 찾아요
   - **비슷한 욕구 구별하기**: 들어 줌·알아줌·위로·곁에 있어 줌처럼 비슷한 욕구는 "그때 바랐던 것" 문장으로 한 번 더 골라요
   - **지금은 넘어가기**: 바로 "이름 붙이기 어려운 욕구"로 저장해요
7. **결과 카드** — 감정·강도·욕구·한 줄 정리·작은 실천 제안

"이 중엔 없어요"(5번)를 누르면 질문 방법이 바뀌어요.
몸 감각 → 하고 싶었던 행동 → 욕구부터 거꾸로 → 비슷한 옛 경험 → 그래도 없으면 "지금은 이름 붙이기 어려운 감정"으로 저장해요.

**재미 요소**: 감정 도감(558개 단어 모으기, 찾은 단어를 누르면 설명·처음 찾은 날·찾은 횟수가 나와요), 숨은 감정 ★ 보너스(24개), 연속 기록 일수, 주간 감정 보고서(막대그래프)

**기록**은 휴대폰 브라우저 안에만 저장돼요. 서버·AI·로그인이 없어요. 처음 화면 맨 아래 "기록 전체 삭제" 버튼으로 모두 지울 수 있어요.

## 기록 옮기기 (휴대폰을 바꿀 때) 💾

기록은 휴대폰 안에만 있어서, 휴대폰을 바꾸거나 브라우저 데이터를 지우면 사라져요. 그 전에 파일로 저장해 두세요.

1. 옛 휴대폰: 처음 화면 → **기록 옮기기** → **파일로 저장하기**
   (또는 **다른 앱으로 보내기**를 눌러 메일·드라이브·메신저 "나에게 보내기"로 보내요. 이 버튼은 지원하는 휴대폰에서만 보여요.)
2. 그 파일(`maeum-chatgi-backup-날짜.json`)을 새 휴대폰으로 옮겨요.
3. 새 휴대폰: 처음 화면 → **기록 옮기기** → **파일 고르기** → 파일 선택 → **네, 불러올게요**

- 불러오면 지금 있는 기록은 **그대로 두고** 새 기록만 더해요. 이미 있는 기록은 건너뛰어요.
- 도감·연속 기록·주간 보고서는 기록에서 다시 계산되니 함께 옮겨져요.
- ⚠️ 파일 안에는 적은 글이 그대로 들어 있어요. 다른 사람에게 보내지 않도록 조심하세요.

## 문장 고치는 방법 ✏️

게임에 나오는 **모든 단어와 문장**은 `data` 폴더 안 파일 3개(`emotions.js`, `needs.js`, `questions.js`)에 들어 있어요. `data/safety.js`는 지금 쓰지 않는 보관용 목록이에요.
코드를 몰라도 **따옴표 안의 글자만** 바꾸면 돼요.

| 파일 | 들어 있는 것 |
|---|---|
| `data/emotions.js` | 감정 단어 558개와 설명 (같은 뜻 다른 말 포함), 비슷한 감정 구별 질문(`ask`, `compareSets`), 단어로 찾기 추천(`searchSuggest`) |
| `data/needs.js` | 욕구 단어 52개, 문장, 작은 실천 제안, 욕구 쪽(`needGroups`), 감정별 첫 욕구(`needsByEmotion`), 비슷한 욕구 구별(`ask`, `needCompareSets`), 욕구 찾기 추천(`needSearchSuggest`) |
| `data/questions.js` | 질문 문장, 버튼 글자, 안내 문장, 한 줄 정리 문장, 게임 방법 안내 카드(`intro`) |
| `data/safety.js` | 위험한 말 목록 (지금은 게임에서 쓰지 않음, 목록만 보관) |

### 따라 하기 (GitHub 웹사이트에서)

**1단계.** GitHub에서 이 저장소를 열어요.

**2단계.** `data` 폴더를 누르고, 고치고 싶은 파일(예: `questions.js`)을 눌러요.

**3단계.** 오른쪽 위의 **연필 모양 ✏️ 버튼**을 눌러요.

**4단계.** 바꾸고 싶은 문장을 찾아요.
   찾기가 어려우면 키보드에서 `Ctrl` + `F`(맥은 `⌘` + `F`)를 누르고 그 문장의 일부를 적어 보세요.

**5단계.** **따옴표 `' '` 안의 글자만** 바꿔요.

예를 들어 이 줄이 있으면

```js
  situationTitle: '오늘 어떤 일이 있었나요?',
```

이렇게 바꿔요.

```js
  situationTitle: '오늘은 무슨 일이 있었어요?',
```

**6단계.** 오른쪽 위 초록색 **Commit changes...** 버튼 → 다시 한 번 **Commit changes**를 눌러요.

**7단계.** 1~2분 기다린 뒤 휴대폰에서 앱을 껐다가 다시 열면 바뀐 문장이 보여요.
   (바로 안 바뀌면 한 번 더 껐다가 열어 보세요.)

### 꼭 지켜야 할 약속 4가지 ⚠️

1. **따옴표 `'`를 지우지 마세요.** 문장 앞뒤에 하나씩 꼭 있어야 해요.
2. **문장 안에 작은따옴표 `'`를 쓰지 마세요.** 대신 큰따옴표 `"`를 쓰세요.
   - ❌ `'나는 '괜찮아'라고 말했어요'`
   - ✅ `'나는 "괜찮아"라고 말했어요'`
3. **줄 끝의 쉼표 `,` 와 괄호 `{ } [ ]`는 그대로 두세요.**
4. **`id: '...'` 부분과 영어 이름표는 바꾸지 마세요.** (예: `id: 'joy01'`, `emotions: ['joyH1', ...]`)
   기록과 도감이 이 이름표로 연결돼 있어요. 감정 단어(`word`)와 설명(`desc`)은 마음껏 바꿔도 돼요.

### 문장 속 `{ }` 표시

`data/questions.js`의 한 줄 정리 문장에는 `{감정을}` 같은 표시가 있어요.
앱이 이 부분에 알맞은 말을 넣어 줘요. **중괄호째로 지우지 말고, 그 앞뒤 말만 바꾸세요.**

| 표시 | 바뀌는 말 (예) |
|---|---|
| `{원인}` | 그 사람의 말에서 |
| `{감정을}` | 서운함을 / 짜증을 (을·를을 앱이 알아서 맞춰요) |
| `{강도}` | 많이 |
| `{욕구가}` | 들어 주는 것이 (이·가를 앱이 알아서 맞춰요) |

### 잘못 고쳐서 화면이 이상해졌다면

- 화면에 **"데이터 파일에 문제가 있어요"**가 나오면, 거기 적힌 파일에서 마지막으로 고친 줄의 따옴표·쉼표를 확인하세요.
- 되돌리고 싶으면: 그 파일을 열고 오른쪽 위 **History**(기록)를 눌러, 전에 잘 되던 때의 내용을 보고 똑같이 고쳐 적으면 돼요.

### 감정 단어를 새로 더하고 싶다면

화면 한 장에 단어 4개가 나와요. 그래서 단어는 **묶음 하나(단어 4개)씩** 더해요.

1. `data/emotions.js`에서 더하고 싶은 쪽(예: 슬픔 쪽)의 `groups` 목록 맨 끝 묶음을 복사해 그 아래에 붙여요.
2. `label`(묶음 이름), `hint`(묶음 설명), 단어 4개의 `word`·`desc`를 새로 적어요.
3. 새 단어의 `id`는 **아직 안 쓴 번호**로 적어요. (예: 슬픔 쪽 마지막이 `sad32`라면 `sad33`~`sad36`)
   이미 있는 id는 바꾸거나 지우지 마세요.
4. 묶음이 4개를 넘으면 묶음 고르기 화면이 자동으로 여러 장이 돼요.
5. 뜻이 아주 비슷한 단어는 **서로 다른 묶음**에 넣어 주세요. 단어별 구분 기준은 `docs/emotion-words-research.md`에 있어요.
6. 뜻이 **같은** 다른 말은 그 단어의 `same` 목록에 더해요. (3개까지)
   ```js
   { id: 'sad05', word: '실망', desc: '...', same: [{ id: 'sad05a', word: '낙담' }, { id: 'sad05b', word: '낙심' }] }
   ```
   id는 원래 단어 id 뒤에 a, b, c를 붙여요.

### 비슷한 감정 구별 질문 고치기

`data/emotions.js` 맨 아래 `compareSets`에 감정 4개씩 한 줄로 적혀 있어요. 화면에 나오는 문장은 각 감정의 `ask`예요.
문장은 마음껏 고쳐도 되고, 줄을 더할 때는 그 줄의 감정 4개 모두에 `ask`를 적어 주세요. 숨은 감정은 넣지 마세요.

숨은 감정을 더하고 싶다면 `hidden` 목록에 한 줄을 더하고, `data/questions.js`의 `approaches` 안 `emotions` 목록 중 한 곳에 그 id를 넣어야 게임에서 만날 수 있어요.

## 자동 점검 (개발자용)

Node.js와 Playwright(Chromium 포함)가 설치된 컴퓨터에서:

```bash
node tests/run-tests.js
```

휴대폰 화면 너비 360·390·430px에서 다음을 실제로 눌러 확인해요.

- 처음 열 때만 게임 방법 안내 3장이 나오는지 (이전·다음·건너뛰기, 메뉴에서 다시 보기, 기록이 있는 사람에게는 안 나옴)
- 묶음이 4개를 넘는 쪽에서 5번 "다른 묶음 더 보기"로 다음 장이 나오고, 마지막 장의 5번은 질문 방법을 바꾸는지
- 처음 만든 감정 id 88개가 그대로 있는지, 묶음마다 단어 4개인지, 비슷한 단어가 같은 화면에 함께 나오지 않는지
- 같은 뜻 다른 말 화면이 나오고 고른 말이 결과 카드에 그대로 나오는지
- 비슷한 감정 구별 화면이 나오고, 구별 질문으로 다른 감정(예: 수치심 → 죄책감)을 골라도 결과 카드까지 가는지
- 단어로 찾기 → 고르기 → 결과 카드 ("부끄러웠다"·"미안했다"·"놀랐다" 같은 말로 찾기, 찾기 입력칸 글자 16px 이상)
- 핵심 감정이 각 쪽 묶음 고르기 1장에 있는지
- 첫 화면 감정 쪽 7개(두 줄)와 "잘 모르겠어요", 7쪽 각각 처음부터 결과 카드까지
- 옛 기록의 쪽 값이 지금 데이터에 맞게 바뀌는지 (예: 창피함 기록 → 부끄러움·미안함 쪽)
- 감정별 첫 욕구 보기, 욕구 쪽 고르기(2장) → 쪽 안 욕구(여러 장), 욕구 단어로 찾기, 비슷한 욕구 구별, 지금은 넘어가기
