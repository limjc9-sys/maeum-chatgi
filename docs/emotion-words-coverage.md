# 감정 단어 대응표

원자료 단어가 게임의 어느 단어로 들어갔는지 정리한 표입니다. 이 파일은 data/emotions.js와 tests/source-word-map.json에서 만들었습니다.

- 원자료: 무드 미터 100칸(마크 브래킷, 『감정의 발견』, 북라이프) / 손선주·박미숙·박지은·손진훈(2012), 「한국어 감정표현단어의 추출과 범주화」, 감성과학 15(1), 부록 1-1~1-3(504개)
- 합계 604칸 = 대응표 578칸 + 욕설·비하어 26칸
- 욕설·비하어 26칸(손선주 외 부록 1-1 분노 범주)은 감정 이름이 아니고 비하 표현이라 게임 단추로 만들지 않았고, 저장소에도 적지 않았습니다. 모두 화남 쪽 "분노"에 해당하는 표현으로 봅니다.
- 웃음·울음 소리, 감탄사는 문장("~을 느꼈어요")에 넣을 수 없어 가장 가까운 게임 단어로 대응했습니다.
