# 「내 마음 찾기」 근거 종합 점검 (메타 분석)

작성: 2026-11-07. 지시: "착잡함 같은 복합 감정을 찾기 어렵다. 체크를 두 개 이상 할 수 있게 개선. 아직 많이 부족하다. 메타 분석을 실시하라."

---

## 1. 방법과 한계

- **이 문서가 하는 일**: 이미 발표된 메타분석·체계적 문헌 검토의 결론을 모아, 앱의 기능 하나하나가 그 결론과 맞는지 대조했습니다(여러 메타분석을 묶어 보는 "종합 검토" 방식).
- **하지 않은 일**: 효과 크기를 직접 모아 다시 계산하는 통계적 메타분석은 하지 않았습니다. 까닭: ① 이 앱의 사용 자료(기록·효과 측정)가 없음 ② 아래 연구들은 대상·측정이 서로 달라 한 숫자로 합치면 뜻이 없음.
- **확인 수준**: 서지(저자·연도·학술지·권·쪽)는 검색으로 확인했습니다. M1·M7은 원문을 대조했고(6절), 나머지는 **초록과 2차 요약**으로만 확인했습니다. 원문 표·수치를 직접 대조하지 않은 곳은 "(초록)"·"(2차 요약)"으로 적었습니다.
- **판정 기호**: ✅ 근거와 맞음 / △ 일부만 맞음 / ✕ 빈 곳.

## 4. 이번에 고친 것

1. **여러 감정 체크(최대 3개)**: 단어를 누르면 ✓ 표시가 되고 다시 누르면 풀림. 화면 위쪽 "고른 감정" 막대에서 ✕로 뺌. "다른 쪽에서 더 고르기"로 쪽을 넘나들며 모음. 단어로 찾기 결과도 체크.
2. **감정마다 강도**: 고른 감정 수만큼 강도를 따로 물음(예: 착잡함 7점, 미묘함 4점, 기쁨 2점).
3. **결과 카드·기록**: 감정 여러 개와 각 강도를 함께 보여 주고, 한 줄 정리에 "착잡함, 미묘함과 기쁨을"처럼 이어 씀. 도감·주간 보고서·지난 기록·파일 불러오기가 여러 감정을 모두 셈. 옛 기록(감정 1개)은 그대로 읽음.
4. **섞인 마음 쪽**: 여러 마음이 뒤섞여요(착잡함·복잡미묘함·만감이 교차함·갈팡질팡함), 좋으면서 슬퍼요(시원섭섭함·웃픔·고마우면서 미안함·달콤씁쓸함), 좋으면서 싫어요(애증·축하하면서 부러움·반가우면서 어색함·하고 싶으면서 두려움). 새 단어 11개 + 같은 뜻 다른 말 7개. 착잡함(id sad45)은 섞인 마음 쪽으로 옮기고, 그 빈 곳에 "마음이 무거움"(sad57)을 넣음. 전체 538개에서 558개로 늘어남.
5. 감정을 하나만 골랐을 때만 비슷한 감정 구별 질문을 함. 여러 개를 고르면 이미 마음을 나누어 고른 것이므로 건너뜀(설계 판단).

## 5. 개선안 진행 (2026-11-07 승인분)

| 번호 | 개선안 | 결과 |
|---|---|---|
| 1 | 주간 보고서에 서로 다른 감정 수·섞인 마음 기록 수 | 반영. "서로 다른 감정" = 그 주 기록에 나온 감정 단어 수, "섞인 마음 기록" = 감정 2개 이상이거나 섞인 마음 쪽에서 고른 기록 |
| 2 | 결과 카드 아래 "그 감정이 나에게 무엇을 말해 주나요?" | 반영. 적지 않아도 됨, 300자까지, 카드·지난 기록·기록 파일에 저장, 나중에 고쳐 저장 가능 |
| 3 | 강도 변화 그래프, 자주 함께 나온 감정·욕구 짝 | 반영. 하루 평균 강도 꺾은선(그날 기록의 모든 감정 강도 평균, 요일별 숫자 함께), 감정 → 욕구 짝 상위 5개 막대 |
| 4 | 매일 알림(달력 파일) | 하지 않음 (사용자 판단: 불필요) |
| 5 | "잘 모르겠어요" → 기분 4칸 | 반영. 기분 나쁨·좋음 × 힘이 넘침·빠짐 4칸, 칸마다 감정 4개. 5번 "이 중엔 없어요"는 지금처럼 몸 감각 → 행동 → 거꾸로 → 옛 경험 |
| 6 | "이 욕구가 맞았나요? 네 / 아니요 / 잘 모르겠음" | 반영. 응답은 기록과 기록 파일에 남음. 같은 감정(같은 뜻 다른 말 포함)을 다시 고르면 "네"가 많았던 욕구는 첫 욕구 보기 앞에, "아니요"가 더 많았던 욕구는 빠짐. 주간 보고서에 응답 수 |

6번의 반영 방식(같은 사람 기록 안에서 순서 바꾸기)은 작성자 설계입니다. 여러 사람의 응답을 모아 needsByEmotion 자체를 고치려면 tools/needfit-report.js로 기록 파일들을 모아 빼기·넣기 후보를 봅니다(README "욕구 응답 모으기"). 서버가 없어 앱이 자동으로 모으지는 않고, 2026-11-07 현재 모은 기록 파일이 없어 needsByEmotion은 고치지 않았습니다.
