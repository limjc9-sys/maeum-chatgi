## 3. 사람이 결정·지시한 사항 (날짜순)

출처 표시: [커밋] 저장소 커밋 기록, [규칙] `docs/design-rules.md`, [조사] `docs/emotion-words-research.md`, [메타] `docs/meta-analysis.md`, [대화] 2026-11-07 작업 대화.

### 2026-11-05 — 처음 만들기
- 감정을 탐색하는 휴대폰 웹앱을 만들기로 기획 [커밋 「내 마음 찾기」 감정 탐색 게임 웹앱 추가]. 처음 기획 지시의 원문은 저장소에 없음(8절).
- 도감, 기록 내보내기·불러오기, 첫 실행 안내, 감정 단어 확대(88 → 148개) [커밋].

### 2026-11-06 — 낱말과 핵심 감정
- 사용자가 준 원자료(무드 미터 100칸, 논문 부록 504칸)의 감정 단어가 **모두 들어가도록** 지시 [조사 7절].
- 핵심 감정(수치심·두려움·분노·상실·슬픔·죄책감·놀람·역겨움 등)을 쉽게 찾게 하라고 지시 [조사 8절].
- 상담 전화 안내 화면과 문구 삭제 지시 [메타].
- 핵심 감정을 첫 화면 쪽으로 올리고, 욕구 고르기도 같은 기준으로 보완하라고 지시. 설계안을 승인한 뒤 구현 [조사 9절].

### 2026-11-07 오전 — 전면 재설계
- "착잡함 같은 복합 감정을 찾기 어렵다. 체크를 두 개 이상 할 수 있게. 메타 분석을 실시하라" [메타].
- 조사자료 「'감정과 욕구 찾기' 앱 설계를 위한 핵심이론과 감정·욕구 낱말 풀」 제공 → 기분 4칸 × 범주, 욕구 14범주 구조의 근거 [조사 13절].
- 지적 1~4 [규칙 1~3]: 앱 이름 "감정 및 욕구 찾기", 제목 위 하트 없음, 메뉴 4개 한 줄, "게임 방법" 대신 "사용 방법", 설치 방법과 참고자료는 사용 방법 안에. 감정·욕구 **개수 제한 없음**, "섞인 마음 쪽" 해체(여러 감정은 각각 고름). **핵심 감정 5개 지정**(수치심·분노·두려움·상실감·슬픔). 강도 화면·마음 카드의 핵심 낱말 강조.

### 2026-11-07 오후 — 화면 정비 (작업 대화, 지적과 결정)
1. 감정 고르기 첫 화면이 "난잡하다" → 단순하고 체계적으로 정비. 핵심 감정을 **6개로**(짝이 맞지 않는 빈 칸이 보기 안 좋음). 참고자료는 눌러야 보이게. 검은 시작 단추 → **편안한 파랑**. 어린이·어르신도 쉽게 쓰도록 보완 [규칙 5]. (6번째 낱말로 죄책감을 고른 것은 AI의 제안)
2. 마음 카드의 "작은 실천 제안"과 "그 감정이 나에게 무엇을 말해 주나요?" **삭제** — 생뚱맞고 예시가 엉뚱함 [규칙 6].
3. **모든 화면에 이전 단계 단추**, 돌아가도 체크·입력이 남아야 함(마지막 단계 포함), 이를 사용 방법에 설명 [규칙 6].
4. 감정이 40개 넘게 고른 경험에서, 강도 단계에 **보류·빼기 단추**가 필요하다고 결정 [규칙 6].
5. 처음 화면 글자 **가운데 맞춤**, 기록 요약 줄은 **아래쪽**으로 [규칙 7].
6. "핵심 감정" → **"핵심 감정으로 찾기"** 명칭. "'무시당한' 같은 말로 찾기"가 한 예에만 묶인 **명백한 잘못**이라고 지적 [규칙 7].
7. 세 찾기 방법의 관계가 모호하다고 지적하고 **위계를 결정**: 기분 4칸으로 찾기(맨 위) → 핵심 감정으로 찾기 → 다른 방법으로 찾기. "기분이 나쁘고" → **"기분이 안 좋고"** [규칙 7].
8. 지난 기록에 **삭제·수정·피드백** 기능, 감정 도감을 **목록 + 누르면 쉬운 설명**으로 완전 수정, 모든 화면에 **앞으로·뒤로 단추**를 체계적·일관되게 [규칙 8·9].
9. **보너스별 삭제**. 도감의 초록·빨강·파랑 **색이 안 맞는다**고 지적. 도감 낱말 밑 설명 삭제, **2개씩 나란히**, + 단추는 **뜻·비슷한 말·반대말 3가지만** [규칙 10].
10. 반영할 때마다 병합(공개)을 직접 승인: [#1](https://github.com/limjc9-sys/maeum-chatgi/pull/1) · [#2](https://github.com/limjc9-sys/maeum-chatgi/pull/2) · [#3](https://github.com/limjc9-sys/maeum-chatgi/pull/3) · [#4](https://github.com/limjc9-sys/maeum-chatgi/pull/4).

## 4. 선택과 배열 (편집저작물로 볼 여지가 있는 부분)

사람이 고르고 차례를 정한 짜임이에요. 기능·아이디어 자체가 아니라 **이 구체적인 짜임**을 주장해요.

- **6단계 흐름**: 있었던 일 → 감정 고르기 → 강도 → 원인 → 욕구 고르기 → 마음 카드.
- **감정 고르기 위계**: ① 기분 4칸으로 찾기 → ② 핵심 감정으로 찾기 → ③ 다른 방법으로 찾기(낱말로 찾기 · 상대가 나에게 한 일로 찾기 · 잘 모르겠어요).
- **핵심 감정 6개**(3개씩 두 줄): 수치심 · 죄책감 · 분노 · 두려움 · 상실감 · 슬픔. 5개는 사람이 지정, 6개로 한다는 결정도 사람.
- **기분 4칸 이름**: 노랑 "기분이 좋고 힘이 넘쳐요", 초록 "기분이 좋고 차분해요", 빨강 "기분이 안 좋고 힘이 세요", 파랑 "기분이 안 좋고 힘이 빠져요".
- **낱말 범위**: 원자료 604칸 전부 포함(욕설·비하어 26칸 제외), 조사자료의 낱말 풀 반영, 개수 제한 없는 고르기.
- **화면 규칙**: 모든 화면 아래 "← 이전 / 다음 →", 입력 유지, 강도 보류·빼기, 마음 카드 구성(감정·강도·보류한 감정·욕구·한 줄 정리), 도감 구성(2개씩, 뜻·비슷한 말·반대말).
- **뺀 것**: 상담 전화 화면, 게임식 보너스별, 실천 제안, 성찰 질문, 섞인 마음 쪽, 개수 제한.

## 5. 생성형 AI가 만든 부분 (등록할 때 밝히고 빼야 할 부분)

- 코드 전부: `index.html`, `css/style.css`, `js/app.js`, `sw.js`, `tests/`, `tools/`.
- 문장 초안: 안내 문장, 감정 낱말 뜻풀이(desc), 욕구 설명, 한 줄 정리 문장 틀.
- AI가 정한 세부: 감정 낱말의 칸·범주 배치(조사자료를 바탕으로 한 추정), 반대말 304개 + 범주별 28개, "상대가 나에게 한 일" 여섯 묶음의 나눔과 이름, 얼굴 그림 고르기, 색 값, 6번째 핵심 감정(죄책감) 제안.
- 근거 조사 문서 정리: `docs/emotion-words-research.md`, `docs/meta-analysis.md`, `docs/emotion-words-coverage.md`.
