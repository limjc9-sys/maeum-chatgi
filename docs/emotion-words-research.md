## 2. 지금 목록의 문제 (사실)

- 큰 쪽 4개 × 묶음 4개 × 단어 4개 = 64개 + 숨은 감정 24개 = 88개.
- 가장 기본이 되는 낱말이 없음: 기쁨, 행복함, 슬픔, 불안함 (S1에서 원형성이 가장 높은 쪽의 낱말).

## 3. 비슷한 단어의 구분 기준

같은 화면에 두지 않는 대신, 각 단어가 무엇으로 다른지 설명(desc)에 드러나게 했습니다.

| 단어 묶음 | 나누는 기준 |
|---|---|
| 무서움 / 두려움 / 겁남 | 무서움 = 지금 눈앞의 위험. 두려움 = 앞으로 닥칠 큰일. 겁남 = 해 보기 전에 용기가 안 남 |
| 걱정 / 초조함 / 조마조마함 / 안절부절 / 불안함 | 걱정 = 나쁜 일을 자꾸 생각함. 초조함 = 시간에 쫓김. 조마조마함 = 결과를 기다림. 안절부절 = 몸이 가만있지 못함. 불안함 = 까닭 모르게 마음이 놓이지 않음 |
| 짜증 / 귀찮음 / 성가심 | 짜증 = 신경이 곤두섬. 귀찮음 = 하기 싫음(힘이 없음). 성가심 = 남이 자꾸 방해함 |
| 창피함 / 민망함 / 쑥스러움 / 수치심 | 창피함 = 실수가 남에게 드러남. 민망함 = 상황이 어색함. 쑥스러움 = 칭찬·관심을 받아 낯간지러움. 수치심 = 나라는 사람 자체가 부끄러움(S8) |
| 죄책감 / 자책감 / 미안함 / 후회 | 죄책감 = 내 행동이 남을 힘들게 함(S8). 자책감 = 나를 꾸짖음. 미안함 = 상대에게 마음이 쓰임. 후회 = 지난 선택을 되돌리고 싶음 |
| 부러움 / 샘남 / 질투 | 부러움 = 남이 가진 것을 나도 갖고 싶음. 샘남 = 남이 잘되는 게 싫음. 질투 = 아끼는 사람을 빼앗길까 봐(S9) |
| 기쁨 / 행복함 / 즐거움 계열 | 기쁨 = 바라던 일이 이루어짐(결과). 행복함 = 지금 이대로 좋음(전체). 재미있음 = 웃음이 남(과정) |
| 뿌듯함 / 자랑스러움 / 보람 | 뿌듯함 = 내가 해낸 일로 마음이 참. 자랑스러움 = 남에게 보여 주고 싶음. 보람 = 한 일이 누군가에게 도움이 됨 |
| 신기함 / 깜짝 놀람 / 철렁함 | 신기함 = 좋은 놀람(기쁨 쪽). 깜짝 놀람 = 갑작스러움(중립). 철렁함 = 나쁜 소식에 놀람 |
| 무서움 / 끔찍함 | 무서움 = 위험이 다가옴. 끔찍함 = 너무 나쁜 장면이라 떠올리기 싫음(S7의 fear와 horror) |
| 역겨움 / 징그러움 / 정떨어짐 / 한심함 | 역겨움 = 속이 메스꺼움. 징그러움 = 보기만 해도 몸이 움찔함. 정떨어짐 = 사람에게 마음이 식음. 한심함 = 하찮게 보임 |

## 7. 2차 정비: 원자료 단어 모두 넣기 (2026-11-06)

지시: 사용자가 제공한 자료(S10 무드 미터 100칸, S2 부록 504칸)의 감정 단어가 모두 들어가도록 정비.

**구조**
- 뜻이 같은 말(예: 실망·낙담·낙심·낙망)을 따로따로 단추로 만들면 문제 ①(비슷한 단어가 한 화면에 겹침)이 다시 생기고, 묶음 고르기가 10장 넘게 길어집니다.
- 그래서 단어를 "뜻 무리"로 묶었습니다. 묶음 화면에는 뜻 무리의 대표 단어 4개가 나오고, 그 대표 단어를 고르면 "같은 뜻 다른 말" 화면에서 정확한 낱말(최대 4개)을 고릅니다.
- 같은 뜻 다른 말도 각각 id가 있어 기록·도감에 따로 남습니다(id는 대표 단어 id + a·b·c).
- 묶음 수: 기쁨 12, 슬픔 14, 화남 10, 불안·두려움 11(묶음 고르기 3~4장).

**넣는 방식**
- 그대로 넣음: 감정 이름으로 쓸 수 있는 말은 게임 낱말 꼴로 바꿔 넣었습니다(가련하다→가련함, 격분한→격분).
- 같은 단어의 다른 꼴은 하나로 셉니다: 기쁘다·기쁜→기쁨, 슬퍼하다·슬픈→슬픔.
- 소리·감탄사 43칸(42개 낱말, 아휴는 두 번 나옴. 까르르, 흑흑, 헉, 아야 등)은 "~을 느꼈어요" 문장에 넣을 수 없어 가장 가까운 게임 단어로 대응했습니다(웃음이 터짐, 울음이 터짐, 깜짝 놀람, 아픔 등).
- 넣지 않음: 욕설·비하어 26칸(S2 분노 범주). 감정 이름이 아닌 비하 표현이라 단추로 만들지 않았고 저장소에도 적지 않았습니다. 모두 "분노"에 해당하는 표현으로 봅니다.
- 뜻을 확인하지 못한 2칸: 거치잡다 → 불쾌함, 갈괄다 → 고약함(추정 대응).

**결과**: 게임 단어 148개 → 538개(뜻 무리 212개 + 같은 뜻 다른 말 326개). 원자료 604칸 = 대응 578칸 + 욕설 26칸.
전체 대응표와 배치표: docs/emotion-words-coverage.md. 자동 테스트가 대응표의 게임 단어가 모두 있는지 검사합니다.

## 8. 3차 정비: 핵심 감정 쉽게 찾기, 가장 가까운 감정 고르기 (2026-11-06)

지시: 핵심 감정(수치심·두려움·분노·상실·슬픔·죄책감·놀람·역겨움 등)을 쉽게 찾게 하고, 가장 가까운 감정을 고르기 쉽게 고침.

### 8-1. 추가 자료 (서지는 검색으로 확인, 본문은 초록·2차 요약 수준)

### 8-2. 무엇이 어려웠나 (지금 구조의 사실)

- 쪽 고르기 → 묶음(최대 4장) → 단어 → 같은 뜻 다른 말, 4단계를 거쳐야 함. 기본 낱말(슬픔·죄책감·화남·분노·역겨움·불안함·놀람)이 2~3장에 있었음.
- 비슷한 단어를 일부러 다른 묶음에 나눠 두어(4번), 한 화면에서 서로 견줄 수 없음.
- 같은 뜻 다른 말 화면이 "어느 말이 가장 가까운가요?"라고 물었으나, 보기의 설명이 모두 "○○과 같은 뜻이에요"라서 고를 기준이 없었음.
