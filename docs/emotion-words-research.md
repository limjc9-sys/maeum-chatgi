# 감정 단어 조사와 묶음 배치

「내 마음 찾기」 감정 고르기 단계를 고치기 위한 조사·후보 정리 파일입니다.
해결할 문제: ① 비슷한 단어가 한 화면에 겹쳐 나옴 ② 정확한 감정을 고를 표현이 없음 ③ 단어와 선택지가 부족함.

## 1. 출처와 확인 수준

## 2. 지금 목록의 문제 (사실)

- 큰 쪽 4개 × 묶음 4개 × 단어 4개 = 64개 + 숨은 감정 24개 = 88개.
- 가장 기본이 되는 낱말이 없음: 기쁨, 행복함, 슬픔, 불안함 (S1에서 원형성이 가장 높은 쪽의 낱말).

- 같은 화면의 비슷한 단어: 무서움·겁남·두려움, 걱정·초조함·조마조마함·안절부절, 짜증·귀찮음·성가심, 무시당한 느낌·얕보인 느낌, 외로움·쓸쓸함, 허탈함·김빠짐, 지침·무기력, 뿌듯함·자랑스러움, 당당함·자신 있음, 신남·들뜸, 부담감·압박감, 위축됨·주눅 듦, 긴장됨·떨림.

## 3. 비슷한 단어의 구분 기준

같은 화면에 두지 않는 대신, 각 단어가 무엇으로 다른지 설명(desc)에 드러나게 했습니다.

| 단어 묶음 | 나누는 기준 |
|---|---|
| 무서움 / 두려움 / 겁남 | 무서움 = 지금 눈앞의 위험. 두려움 = 앞으로 닥칠 큰일. 겁남 = 해 보기 전에 용기가 안 남 |
| 걱정 / 초조함 / 조마조마함 / 안절부절 / 불안함 | 걱정 = 나쁜 일을 자꾸 생각함. 초조함 = 시간에 쫓김. 조마조마함 = 결과를 기다림. 안절부절 = 몸이 가만있지 못함. 불안함 = 까닭 모르게 마음이 놓이지 않음 |
| 짜증 / 귀찮음 / 성가심 | 짜증 = 신경이 곤두섬. 귀찮음 = 하기 싫음(힘이 없음). 성가심 = 남이 자꾸 방해함 |
| 창피함 / 민망함 / 쑥스러움 / 수치심 | 창피함 = 실수가 남에게 드러남. 민망함 = 상황이 어색함. 쑥스러움 = 칭찬·관심을 받아 낯간지러움. 수치심 = 나라는 사람 자체가 부끄러움(S8) |
| 죄책감 / 자책감 / 미안함 / 후회 | 죄책감 = 내 행동이 남을 힘들게 함(S8). 자책감 = 나를 꾸짖음. 미안함 = 상대에게 마음이 쓰임. 후회 = 지난 선택을 되돌리고 싶음 |
| 부러움 / 샘남 / 질투 | 부러움 = 남이 가진 것을 나도 갖고 싶음. 샘남 = 남이 잘되는 게 싫음. 질투 = 내 사람·자리를 빼앗길까 봐(S9) |
| 기쁨 / 행복함 / 즐거움 계열 | 기쁨 = 바라던 일이 이루어짐(결과). 행복함 = 지금 이대로 좋음(전체). 재미있음 = 웃음이 남(과정) |
| 뿌듯함 / 자랑스러움 / 보람 | 뿌듯함 = 내가 해낸 일로 마음이 참. 자랑스러움 = 남에게 보여 주고 싶음. 보람 = 한 일이 누군가에게 도움이 됨 |
| 신기함 / 깜짝 놀람 / 철렁함 | 신기함 = 좋은 놀람(기쁨 쪽). 깜짝 놀람 = 갑작스러움(중립). 철렁함 = 나쁜 소식에 놀람 |
| 무서움 / 끔찍함 | 무서움 = 위험이 다가옴. 끔찍함 = 너무 나쁜 장면이라 떠올리기 싫음(S7의 fear와 horror) |
| 역겨움 / 징그러움 / 정떨어짐 / 한심함 | 역겨움 = 속이 메스꺼움. 징그러움 = 보기만 해도 몸이 움찔함. 정떨어짐 = 사람에게 마음이 식음. 한심함 = 하찮게 보임 |
